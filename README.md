# 职业棱镜

“职业棱镜”是面向高校计算机及相关专业学生的职业认知与情境体验平台，帮助学生理解不同职业的真实工作任务，以及个人已有能力与职业任务之间的关系。

## 第一版范围

第一版优先验证三个职业：

- 软件工程师：突出技术问题解决。
- 产品经理：突出需求冲突下的判断与取舍。
- AI 模型评测：突出模型错误判断与验证。

产品体验闭环为：职业地图 → 认识职业 → 认识能力模型 → 输入个人能力画像 → 情境体验 → 记录表现 → 对比呈现 → 形成新认知。

## 当前状态

仓库已经完成初始化，网站技术栈、视觉设计和实现方案尚待确认。项目不会直接判定用户适合或不适合某个职业，也不会把规划中的调研或试点数据描述为已经完成。

## 项目依据

- `AGENTS.md`：项目长期约束与协作规则。
- `PROJECT_CONTEXT.md`：已确认决定、当前进度和待定事项。
- `references/`：赛事通知与产品定位根文件；根文件保持原样，不应覆盖。
- `docs/superpowers/`：已确认的设计规格与实施计划。
