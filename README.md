# 职业棱镜

AI时代职业认知探索平台。面向大学生，重点关注大一与大三学生，通过理解真实项目，认识 AI 职业解决什么问题、如何工作、需要什么能力。

项目仓库：https://github.com/pxn0412/career-prism

## 当前版本：v0.1

核心单位为“职业＋项目”，内容逻辑为：

项目 → 工作过程 → 能力 → 职业理解 → 行业价值。

- 职业透镜（核心）：项目背景、角色、任务、关键决策、问题、解决方式与职业技能。
- 行业透镜（补充）：需求、供给、利润模式、壁垒、行业周期，帮助理解职业为何出现。
- 个人透镜（未来）：已有能力、职业需要能力、差距与下一步方向。

Demo 坚持少量职业、深度展示，暂定三个左右。候选为 AI 应用工程师（优先）、AI 产品经理、AI 算法/大模型工程师，最终名单尚未确定。

## 当前理解标准

用户看完一个职业透镜后，能用自己的话讲清该职业解决什么问题、在项目中做什么、做哪些关键判断、需要什么能力。

下一步是确定职业透镜标准模板。具体 UI、职业地图、AI 推荐、小游戏和技术方案暂缓确定；目前尚无网站代码。
