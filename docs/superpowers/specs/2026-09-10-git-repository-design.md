# 职业棱镜 Git 仓库设计

## 目标

为“职业棱镜”建立适合持续开发、成员协作和后续公开展示的 Git 仓库，同时保留现有项目依据，不提前锁定网站技术栈。

## 仓库位置与可见性

- 正式开发仓库位于 `C:/Users/27115/Desktop/职业棱镜`。
- Git 默认分支为 `main`。
- GitHub 远程仓库初始设为私有，待参赛版本完成并检查资料发布权限后再决定是否公开。

## 初始内容

仓库首个版本包含：

- `README.md`：项目简介、当前状态和后续开发入口。
- `.gitignore`：忽略依赖、构建产物、环境变量、编辑器缓存和临时文件。
- `AGENTS.md`：跨对话工作约束。
- `PROJECT_CONTEXT.md`：项目决策与进度记录。
- `references/`：用户指定的两份根资料，保持原文件不变。
- `docs/superpowers/specs/`：已确认的设计规格。

## Git 与协作规则

- 首次提交只建立项目基线，不生成前端框架。
- 网站技术栈确定后再创建应用代码。
- 密钥、访问令牌和本地环境变量不得提交。
- 根资料不得被覆盖；新版本通过新增文件和更新版本关系进行记录。
- 对外公开仓库前，单独检查 `references/` 中资料是否适合公开发布。

## 完成标准

1. 桌面目录已创建并可被 Git 正常识别。
2. 初始文件完整，工作区无意外缺失或修改。
3. 首次提交位于 `main` 分支。
4. GitHub 私有仓库已创建并配置为 `origin`。
5. 首次提交已成功推送，且本地工作树干净。

## 暂不包含

- 前端框架、后端服务、数据库或部署配置。
- 网站视觉设计和职业体验内容实现。
- 将仓库公开或发布网站。
